# Reference text

`opensheaf-specification-0.1-full.md` is the specification of PR #30 as it
stood on 18 November 2026 (commit 8e7f26e), after fourteen reviews, with its
full changelog. It was written as revisions of version 0.1, and its format
names are still `opensheaf-<x>/0.1`. It is kept here, unchanged and unbuilt,
as the source from which the specification was rebuilt concept by concept,
on 18 and 19 November 2026, into a shorter, coherent text, which became
version 0.2 ([opensheaf-specification-0.2.md](../opensheaf-specification-0.2.md)).
It is not maintained: where the two differ, version 0.2 is right. Version
0.1 as published is
[opensheaf-specification-0.1.md](../opensheaf-specification-0.1.md).
